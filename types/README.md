# Types Directory

This directory centralizes all TypeScript interface declarations and type aliases:
- `pdf.ts`: PDF document rendering, page callbacks, and bookmark models
- `audio.ts`: Audio state, playback speed, seek gestures, sleep timer configs
- `navigation.ts`: Stack routing parameter definitions
- `storage.ts`: Persistence models for recent files and reading progress
- `picker.ts`: File selector result representations
- `common.ts`: Common error and utility types
